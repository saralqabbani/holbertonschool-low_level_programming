# Simple Calculator

## Description
A simple calculator program written in C.

## Features
- Displays a welcome message.
- Displays a menu of operations.
- Supports menu options for addition, subtraction, multiplication, and division.
- Allows the user to quit using option 0.

## Compilation

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator
